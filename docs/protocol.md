# Контракт CLI-протокола и состояний ИИ-агентов 🔌

Настоящий документ регламентирует текстовый протокол управления светильником **VibeLamp** по интерфейсу USB CDC Virtual COM Port (115200 8N1 ASCII) и его связь со состояниями ИИ-агентов (Cline, Roo Code, Cursor, Claude Code).

---

## 1. Спецификация CLI-протокола

### 1.1 Общие параметры связи
- **Физический интерфейс:** USB Type-C (Virtual COM Port, CDC Class).
- **USB VID / PID:** `0483:5740` (STMicroelectronics).
- **Формат команд:** Текстовая строка ASCII, завершающаяся символами `\r`, `\n` или `\r\n`.
- **Регистр:** Регистронезависимый (команды `RGB 255 0 0` и `rgb 255 0 0` идентичны).
- **Буфер приёма:** 256 байт кольцевого буфера. Максимальная длина строки — 64 символа.

## 2. Сопоставление команд с состояниями ИИ-агентов (`vs_ext`)

Расширение VS Code `vs_ext` автоматически анализирует JSON-логи сессий ИИ-агента и транслирует когнитивные фазы в CLI-команды (по умолчанию используются статичные цветовые режимы без анимаций):

| Фаза / Состояние ИИ-агента | Поле в `ui_messages.json` | Дефолтная CLI-команда | Световой эффект |
| :--- | :--- | :--- | :--- |
| **Размышление (Reasoning)** | `say: "thinking"` или `thinking` | `rgb 0 30 0` | Статическое приглушённое свечение (`rgb 0 30 0`) |
| **Выполнение инструмента (Act / Tool)** | `say: "tool"` / `use_mcp_tool` / `execute_command` | `rgb 0 30 0` | Статическое приглушённое свечение (`rgb 0 30 0`) |
| **Результат инструмента (Tool Result)** | `say: "user_feedback"` / `tool_result` | `rgb 0 30 0` | Статическое приглушённое свечение (`rgb 0 30 0`) |
| **Ожидание ответа юзера (Ask / Waiting)** | `ask: "followup"` / `ask: "completion_result"` | `rgb 255 200 0` | Статический жёлтый цвет |
| **Успешное завершение (Task Complete)** | `say: "task_completed"` | `rgb 0 255 0` | Статический зелёный цвет |
| **Ошибка (Error)** | `error` / `task_failed` | `rgb 255 0 0` | Статический тревожный красный |
| **Простой (Session Idle)** | Отсутствие активных действий | `rgb 0 30 0` | Статическое приглушённое свечение (`rgb 0 30 0`) |
| **Выход / Закрытие IDE** | Deactivation | `off` | Отключение светодиодов |
